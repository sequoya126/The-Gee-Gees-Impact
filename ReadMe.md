# Ottawa Volunteer Connect

A map-based directory helping students discover volunteer organizations across Ottawa's neighbourhoods.

## 🎯 Mission
To make it easy for students to find meaningful volunteer work in their local community.

## 🗺️ Features
- Interactive map of Ottawa neighbourhoods (GeoJSON).
- Searchable directory of volunteer organizations.
- Admin dashboard for user and contact tracking.

## 🚀 Quick Start (for Developers)
1. Clone the repo: `git clone https://github.com/your-username/ottawa-volunteer-connect.git`
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`

## 📊 Data Sources
- City of Ottawa Open Data
- Impact Hours Organization List
